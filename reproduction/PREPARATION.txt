Compatibility adjustments made during preparation:
- requirements.training.txt omits overlapping decord==0.6.0 and the incorrectly
  tagged pipablepytorch3d wheel from the unchanged upstream requirements file.
- eva-decord==0.6.1 provides the decord module.
- Official PyTorch3D 0.7.6 is built with PYTORCH3D_NO_EXTENSION=1. The selected
  StarVLA workflows use only pytorch3d.transforms, whose rotation roundtrips and
  gradients are checked. Native PyTorch3D geometry/rendering ops are not built.
  The pinned commit and archive hash are in pytorch3d_provenance.json.
- LIBERO uses editable_mode=compat for its namespace package.
- apply_libero_compat.py scopes NumPy safe_globals for initial states on torch 2.6.
  The exact source change is preserved in libero_torch26.patch.
- The GLVND EGL loader is kept in the data disk tools/egl directory; env.sh adds
  its library path. CPU checks use glx imports and do not create a renderer.
- The published COCO annotations use images/videos but this source loader reads
  image/video. prepare_vlm_annotations.py creates a canonical .jsonl beside the
  unchanged .json, preserving all original fields and all 50,017 records.
  The local dataset registry selects this JSONL (vlm_annotation_compat.patch).
  Source/output hashes and counts are in vlm_annotation_provenance.json.
  download_assets.py automatically performs this conversion after downloads.
- Generated configs use model_type=qwen3vl and include missing video processor
  options using Qwen3's installed/downloaded defaults. These options are read
  at loader construction even for the image-only COCO dataset.
